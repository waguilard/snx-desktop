# Privacidad y seguridad

El repositorio contiene código genérico y dominios ficticios. No publiques perfiles, certificados, respaldos, registros, capturas ni credenciales. El cliente propietario SNX no forma parte del proyecto.

La aplicación no almacena contraseñas. La autenticación y aceptación de certificados siguen siendo responsabilidad del usuario en la terminal SNX. Revisa la confianza del certificado con tu administrador.

La integración DNS requiere root y compatibilidad con el gestor local. Antes de instalarla, revisa scripts y restricciones del servicio. No cambia las rutas impuestas por el gateway.

Para informar un problema en un repositorio público, usa una reproducción mínima con nombres ficticios y sin secretos. No adjuntes tu perfil ni volcados completos de red.
